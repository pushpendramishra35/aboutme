27 Jul 2026Performance

Shrinking a React Native bundle 15% without cutting features

The 89MB build was mostly leftover native artifacts and unoptimized images bundled after several upgrades. Removing stale architecture outputs, enabling Hermes and Proguard/R8 shrinking, and compressing image assets took it to 76MB — a 15% drop with no feature removed and faster cold starts as a bonus.

27 Jul 2026Reliability

Cutting a React Native crash rate from 2.90% to 1.67%

Most of the crashes traced back to a handful of null-safety gaps and a native-module cleanup that had drifted after upgrades. I triaged the top Crashlytics clusters by impacted-user count (not raw volume), fixed the highest-leverage ones first, and added guards where undefined data crossed the JS–native bridge — taking the production crash rate from 2.90% to 1.67%.

26 Jul 2026React Native

Migrating custom native modules to TurboModules (New Architecture)

Upgrading React Native across 15 minor versions (0.62 → 0.77.2) meant moving custom native modules to TurboModules on iOS and Android. The trick was doing it incrementally — keeping the old bridge working while migrating one module at a time behind the interop layer, so releases never had to stop while the architecture changed underneath.

25 Jul 2026Security

Taking a banking app through penetration testing with zero criticals left

Hardened a regulated banking app with certificate pinning, biometrics/MFA, root/jailbreak detection, anti-tampering, and encryption at rest, then worked with the pen-test team to remediate every finding before store submission — shipping with no open critical or high issues.

24 Jul 2026Compliance

HIPAA-compliant auth shared cleanly across web and mobile

Standardised authentication on Auth0 (OAuth 2.0 / OIDC) so a health-insurance product behaved identically on React web and React Native mobile — one session model, consistent token refresh, and audit-friendly logging that held up to HIPAA review.

23 Jul 2026Architecture

A reusable component library that cut duplicate UI code ~35%

Built a typed component library where every component ships loading, empty, error, and success states by default. Later product teams adopted it, removing roughly a third of the repeated UI implementation work across projects and making new screens far faster to assemble.

22 Jul 2026React Native

Getting BLE reconnect above 99% on a connected-hardware app

A Bluetooth device kept dropping its link when the app backgrounded. Moving re-subscription onto the connection-state callback (instead of component mount) and adding a bounded retry took reconnect success from flaky to consistently above 99% in the field.

21 Jul 2026CI/CD

Automating releases cut turnaround from ~2 days to ~2 hours

Replaced a manual, error-prone release with Fastlane — automated code signing, staged rollouts, and release-health checks on iOS and Android. What used to take a couple of days of careful hand-holding now runs in about two hours, with fewer mistakes.
