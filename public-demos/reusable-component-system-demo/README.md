# Reusable Component System Demo

Original public-safe component examples for ReactJS teams that want consistency without over-engineering.

## What This Demo Shows

- Typed component contracts
- Standard async states
- Separation between shared UI and feature-specific business logic

## Included Sample Files

- `src/ui/Button.tsx`
- `src/ui/DataPanel.tsx`
- `src/ui/StateMessage.tsx`

## Core Rules

- Shared components should expose clear states instead of hidden behavior
- Business rules belong in feature code, not in shared UI primitives
- Repeated product patterns matter more than abstract component quantity

## Why This Exists

This is intended as portfolio-safe proof of frontend system thinking and team-scale maintainability.
